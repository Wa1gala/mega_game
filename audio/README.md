# audio/

Звуки проекта. Формат: `.ogg` для музыки/эмбиента/длинных звуков, `.wav` для коротких SFX (выстрелы, шаги, UI).
Имена: `snake_case`, с вариантами через номер: `rifle_shot_01.wav`, `rifle_shot_02.wav`.
Стиль PSX: можно слегка «грязный» звук, низкий битрейт (22 кГц) — под атмосферу.

| Папка | Для чего |
|---|---|
| `weapons/rifle`, `weapons/knife` | выстрелы, перезарядка, удары, попадания |
| `player/footsteps` | шаги (по типам поверхностей: `carpet_01.wav`, `tile_01.wav`) |
| `player/voice` | голос игрока: дыхание, усталость, смерть |
| `player/hurt` | получение урона |
| `enemy/police` | шаги, оружие, реплики полицейских |
| `enemy/voice` | общие звуки врагов: крики, агро, смерть |
| `items/pickup` | подбор предметов |
| `items/inventory` | перемещение, экипировка, выброс в инвентаре |
| `items/containers` | открытие шкафов/ящиков, замки |
| `ambience/office` | фон офиса: гул ламп, вентиляция, скрипы |
| `ambience/loops` | зацикленные эмбиент-слои |
| `ui/menu` | клики, наведение в меню |
| `ui/hud` | сигналы интерфейса в игре |
| `music/menu` | музыка главного меню |
| `music/gameplay` | музыка в рейде |
| `music/extract` | музыка эвакуации |
| `stingers` | короткие стингеры: тревога, смерть, успешный вынос |
