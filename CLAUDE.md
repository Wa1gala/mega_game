# CLAUDE.md

## О проекте
Кооперативный extraction-рогалик от третьего лица (делаем вдвоём с другом). Лут, инвентарь в стиле Escape from Tarkov, враги, вынос добычи. Стилистика — PSX/PS1: низкополигональные модели, маленькие текстуры, мрачная атмосфера. Не предлагай «современный» реализм — держи визуал в духе PS1.

Сейчас есть: главное меню, пауза, игрок (ходьба/бег/прыжок/стрельба/прицел), инвентарь с сеткой, контейнеры с лутом, подбираемые предметы, уровни-офисы, враг-полицейский (пока стоит в idle).

## Движок и запуск
- Godot 4.7, Forward Plus, физика Jolt, драйвер d3d12 (Windows).
- Godot: `C:\Program Files (x86)\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe`
- Открыть редактор: `<godot.exe> --editor --path .`
- Headless-скрипт (как в tools/): `<godot.exe> --headless --path . --script tools/<имя>.gd`
- Проверка парсинга скриптов без запуска игры: `<godot.exe> --headless --path . --quit`
- Главная сцена: `res://scenes/main_menu.tscn`. Автолоад: `InventoryManager` (`scripts/items/inventory_manager.gd`).
- Ввод (project.godot): `move_*` (WASD/стрелки), `sprint` (Shift), `interact` (E), `inventory` (Tab).

## Структура
- `scenes/` — UI-сцены (главное меню, пауза). `player.tscn` лежит в корне.
- `scripts/` — весь GDScript. `scripts/items/` — инвентарь, предметы, контейнеры, лут-таблицы. `scripts/collision/` — авто-коллизия.
- `resources/items/*.tres` — данные предметов (`ItemData`). `resources/loot/*.tres` — лут-таблицы контейнеров.
- `art/levels/` — уровни и модули (`office_*.tscn`, `base.tscn`, `desks/`, папка `office/` с моделями и текстурами по категориям).
- `art/characters/{player,enemy}/` — модели, анимации (FBX), текстуры. `art/weapons/` — оружие.
- `audio/` — звуки, разложены по категориям (оружие, игрок, враги, предметы, эмбиент, UI, музыка, стингеры). Описание папок — в `audio/README.md`. Пустые папки держатся через `.gitkeep`.
- `tools/` — генераторы: `gen_*.py` создают `.tscn` уровней (правь параметры в скрипте и перегенерируй, а не руками правь сгенерированные сцены — иначе правки затрутся), `make_police_skin.gd` красит текстуру.

## Соглашения
- GDScript, отступы — табы, статическая типизация где возможно (`:=`, `-> void`).
- Комментарии и доки в коде — на русском; держись этого стиля.
- Враги в группе `enemy`, наносимый урон — через `take_damage(amount: int) -> int` (см. `scripts/damageable.gd`).
- Враг использует модель и анимации игрока с другой текстурой (см. `scripts/enemy.gd`).
- Кооп: узел игрока называется peer id, камера/ввод включаются только у локального игрока (`player.gd`, `_enter_tree`). Сетевого спавнера/лобби пока нет; новый геймплейный код пиши с расчётом на мультиплеер (авторитет, RPC), не ломай одиночный запуск сцены.
- `.uid` и `.import` файлы коммитим (кроме папки `.godot/`, она в .gitignore). Не удаляй/не переименовывай ассеты вне редактора Godot без нужды — ломаются UID-ссылки.
